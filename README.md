# AquaWave

Разрабатываемое веб-приложение предназначено для онлайн-бронирования посещений бассейнов и записи на персональные тренировки по плаванию в городе Екатеринбург. Сервис позволит пользователям находить подходящие бассейны из единого каталога, просматривать доступное время посещений, бронировать посещения бассейнов, а также записываться на индивидуальные занятия с тренерами. Кроме того, сервис позволит тренерам управлять своим графиком и взаимодействовать с клиентами, а администраторам - управлять каталогом бассейнов и обрабатывать обращения в поддержку. Платформа обеспечит удобное взаимодействие между клиентами, тренерами и администраторами за счёт централизованной системы онлайн-бронирования и управления расписанием.
